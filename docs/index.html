Metodología

  1. Limpieza (scripts/limpiar.py): se quitan las columnas de método, laboratorio y comentario; se cruzan los metadatos de cada muestra; se conservan las variables químicas con dato en ≥ 5 % de las filas; las coordenadas pasan a grados decimales.
  2. Variables derivadas: año de publicación y número de analitos (discretas), grado de alteración y clase de SiO2 (ordinales).
  3. Análisis exploratorio y estadístico: pendiente.
  4. Machine learning: pendiente (p. ej. clasificar el ambiente tectónico a partir de la química).
